Crolord — by issac
WordPress 6.2+ / PHP 7.4+

与在线站点一致的当前主题源码，包含首页、About、Markets、Wayfarer、Boughs、Keepsakes 和 Echoes 的主题模板及配套资源。

将 crolord 目录放入 wp-content/themes/ 后，在 WordPress 外观中启用。配套插件放入 wp-content/plugins/，分别启用与配置。更新时替换同名目录，保留现有数据库内容、页面、设置和账号授权。

PHP、可读 CSS/JavaScript 与生产资源同时保留。第三方来源与许可随对应文件提供。不要把 WordPress 核心、数据库、wp-config.php、密钥、登录会话、缓存或用户上传文件放进本仓库。
