# Crolord maintenance

- This repository contains the current Crolord theme and its six companion plugins. Keep existing PHP classes, hooks, shortcodes, data types, option names and meta keys compatible.
- Preserve user content, account settings, authentication, authorization, comment moderation and native validation. Never commit secrets, database dumps, sessions, visitor data, caches or uploads.
- Keep the visual language quiet and consistent. Text must not gain underlines on hover, selection or copy. Copying must not include large empty layout regions; preserve code indentation and native inputs. Maintain accessible keyboard focus.
- Preserve the approved 35-pixel transparent logo, native navigation, About carousel timing, existing page titles and the Boughs name.
- Keep initial content visible and avoid global entrance observers. Never delay or intercept native cross-page clicks. Prepare only explicit home/section destinations; honor save-data and slow connections.
- Maintain readable CSS/JavaScript and production bundles together. Use existing per-file asset cache versions. Bump component versions for behavior changes; keep database schema migration versions independent.
- Keep the theme and plugin directories complete, including Echoes runtime source, bundled dependencies, data attribution and third-party licenses. Keep readmes current; do not add old release archives or duplicate version histories.
- Validate PHP, JavaScript, Python and shell syntax as applicable before publishing. Do not execute site deployment scripts or alter production configuration during repository synchronization.
