== Description ==
地点索引、地名标注、本地世界概览与地点联动，支持关联游记和可选详细底图。

== Installation ==
上传并启用后，在 Map 中维护地点与地图设置。既有地点、页面关联和服务配置继续沿用。地图数据来源及第三方许可见 assets/ATLAS-SOURCE.txt 和 assets/vendor/。

请保留随组件提供的第三方许可与来源说明。
