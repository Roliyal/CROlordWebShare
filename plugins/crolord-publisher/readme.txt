== Description ==
文章分发、平台连接、任务队列与媒体处理。平台操作需要相应账号授权，以各平台实际支持的能力为准。

== Installation ==
上传并启用后，在「设置 → Publisher」管理连接，在「工具 → Publisher」查看任务。数据库迁移版本独立于插件版本，保留现有迁移规则。

请保留随组件提供的第三方许可与来源说明。
