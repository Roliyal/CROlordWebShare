== Description ==
独立对话页面、账号连接、文件处理和按需工具调用。运行组件与前端源码均随本目录提供。

== Installation ==
上传并启用后，在「设置 → Echoes」配置访问方式并连接自己的账号。独立运行组件需要 Linux / systemd、Node.js 20+ 和 Python 3.9+；首次安装参见 tools/install-server.sh，自动更新参见 tools/enable-auto-update.sh。保留本机账号授权与桥接密钥，不将运行数据放进仓库。

请保留随组件提供的第三方许可与来源说明。
